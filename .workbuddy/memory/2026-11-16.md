## 首页改造成左右两栏组件切换
- `src/pages/index/index.tsx`：改为 flex 左右布局，左侧列表由 `demos` 数组驱动（GpuCard / ChromeScene / KiraScene），点击切换 `activeKey`，右侧用 `<ActiveComponent key={activeKey} />` 渲染；key 保证切换时 3D 场景重新挂载，避免状态残留。
- `src/pages/index/index.less`：新增 `.demo-layout` 系列样式（侧栏 240px、深色主题、选中高亮），并把 `.three-scene` / `.three-scene-gpu-card` 的高度从 `100vh` 改为 `100%`，使场景填满右栏而非整个视口。
- `src/pages/index/ChromeScene.tsx`：原本按 `window.innerWidth/Height` 渲染，放进右栏会溢出；改为按 `container.clientWidth/Height` 初始化 + `ResizeObserver` 自适应，动画循环改用 `renderer.setAnimationLoop`，卸载时 dispose 几何体/材质/控制器/渲染器。
- 验证：`npx tsc --noEmit` 中 `src/pages/index` 无错误（报错全来自 node_modules 既有依赖类型冲突）；`npm run build:dev` 转换完 2620 个模块后在解析 antd 依赖 `rc-align` 时失败（既有问题，与本次改动无关）；`npm run serve` 启动后首页与 index.tsx 均返回 200，三个组件被正确引入。
